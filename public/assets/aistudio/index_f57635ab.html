Introduction & Overview

Welcome to TokDownloader ("the Utility", "we", "our"). We are committed to maintaining a strictly private, transparent environment for researchers, video editors, and digital archivists.

Core Philosophy: TokDownloader is designed on a Zero-Data-Retention framework. We do not require sign-ins, we do not log passwords, and we never collect, monetize, or harvest personal user information.

This Privacy Policy explains how local storage and outbound HTTPS requests are handled securely while maintaining total privacy.

02

Information Handling & Usage

TokDownloader runs directly on-device without telemetry or behavioral profiling:

  • ✓
    No Account Creation: No email, telephone number, or user authentication is ever required to operate the application.
  • ✓
    No Personal Data Harvesting: We do not track GPS coordinates, device identifiers, contact lists, or background analytics.
  • ✓
    Sandboxed Clipboard Access: The system clipboard is read strictly when you tap the "Paste Link" action, limited solely to the download URL field.
  • ✓
    No Social Account Linking: Downloading public videos never requires binding your personal social media credentials.
03

Android Permissions Explained

In accordance with the Principle of Least Privilege, only the fundamental Android permissions necessary for media retrieval and updates are declared:

android.permission.INTERNET
Authorizes encrypted outbound HTTPS connections to retrieve public media streams directly to your device.
android.permission.ACCESS_NETWORK_STATE
Monitors connectivity status to allow saving mobile data via Wi-Fi-only download toggles.
WRITE_EXTERNAL_STORAGE (maxSdkVersion 28)
Used solely for legacy Android 9 and older devices. Modern releases rely entirely on Scoped Storage.
REQUEST_INSTALL_PACKAGES
Permits launching the verified Android Package Manager when you choose to install an official release update.
04

Media Storage & Security

Every MP4 video or MP3 audio file downloaded is saved locally to your device's standard directories (e.g., /Movies/TokDownloader or /Music/TokDownloader):

  • ✓
    User Sovereignty: You maintain total control over all media files. You can browse, play, share, or delete them anytime using your file manager.
  • ✓
    Zero Cloud Mirroring: We operate no external cloud servers or proxy mirrors that upload or store your downloaded content.
  • ✓
    Encrypted In-Transit: All resolutions and binary transfers operate through modern TLS 1.3 / HTTPS encryption.
05

Third-Party Endpoints & Sharing

TokDownloader interfaces with remote endpoints strictly for functional execution:

  • ✓
    Public Content Delivery Networks (CDNs): Direct streaming links query public delivery networks without transmitting personal authentication cookies.
  • ✓
    Release Verification: The app periodically checks verified version releases via standard read-only requests. No identifying metadata is transmitted.
  • ✓
    System Sharing Intents: Actions like "Copy Caption" or "Share to App" execute through native Android Intent protocols without tracking SDKs.
